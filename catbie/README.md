## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Run the sanity check with `npm run check`.

## Deployment

This is a static repository. Import it into Vercel or Netlify with no build command. The publish/output directory is the repository root (`.`). GitHub Pages can deploy directly from the default branch root.

Point `catbie.xyz` at the selected host after deployment. Canonical and social metadata already use the production domain.
