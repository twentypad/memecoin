# Bored Cat ($BORDCAT)

The launch-ready static website and brand assets for Bored Cat, an original memecoin concept on Base.

> The market is screaming. The cat is napping.

## Included

- Responsive single-page landing site
- Three 1024×1024 mascot logo variants
- 1500×500 X header
- Complete SEO, Open Graph, Twitter Card, and JSON-LD metadata
- Live Base contract details, tokenomics, buying guide, roadmap, FAQ, and disclaimers
- X bio, launch post, reply, and follow-up copy
- Working contract-address copy interaction

## Run locally

No build step or dependencies are required.

```bash
npx serve dist
```

Then open the local URL printed by `serve`.

## Deploy to Vercel

1. Create a new GitHub repository and upload this project.
2. Import the repository into Vercel.
3. Keep the detected framework as **Other**.
4. Deploy. The included `vercel.json` serves the `dist` directory.
